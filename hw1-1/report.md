## 解題說明

本題要求計算阿卡曼函數，計算Ack(m,n)中的數值
### 解題策略

1. 使用遞迴函式將問題拆解為更小的子問題：
   $$\Sigma(n) = n + \Sigma(n-1)$$
2. 當 $n \leq 1$ 時，返回 $n$ 作為遞迴的結束條件。  
3. 主程式呼叫遞迴函式，並輸出計算結果。

## 程式實作

以下為主要程式碼：

```cpp
#include <iostream>
using namespace std;
int Ack(  int m,   int n) {
    if (m == 0) return n + 1 ;
    if (n == 0) return Ack(m - 1, 1 );
    return Ack(m - 1, Ack(m, n - 1));
}
int main() {
      int m;
      int n;
    cout << "輸入 m n : ";
    if (!(cin >> m >> n)) return 0;

      int res = Ack(m, n);
    cout << "Ack(" << m << ", " << n << ") = " << res << endl;
    return 0;
}
```

## 效能分析

1. 時間複雜度：當 m = 0 時，時間複雜度為 $O(1)$。
 當 m = 1 時，Ack(1, n) = n + 2，時間複雜度為 O(n)。
 當 m = 2 時，Ack(2, n) = 2n + 3，時間複雜度為 O(n)。
 當 m = 3 時，Ack(3, n) = 2^{(n+3)} - 3，時間複雜度為 O(2^n)。

 空間複雜度：同時間複雜度一樣

## 申論及開發報告
符合數學定義直觀性阿克曼函數本身即是一個標準的遞迴函數定義。
使用遞迴語法能直接、清楚地將數學公式映射至程式碼中：當  m = 0  時，直接返回  n + 1 。當  n = 0  時，轉化為子問題  Ack(m - 1, 1) 。
當  m > 0  且  n > 0  時，進行雙重遞迴呼叫  Ack(m - 1, Ack(m, n - 1)) 。簡化複雜的狀態管理阿克曼函數具有嵌套遞迴（Nested Recursion）的特性。
若採用非遞迴（迭代）方式實作，開發者必須手動維護一個堆疊（Stack）資料結構來模擬呼叫過程，程式碼會變得相當繁瑣且容易出錯。
採用遞迴能利用編譯器自動維護 Call Stack，極大地簡化了程式邏輯。展示遞迴強大的表達能力與限制阿克曼函數是電腦科學中用來展示遞迴概念與系統限制的最著名範例之一。
透過簡單幾行遞迴程式碼，即可表達極其複雜的計算過程。
